# 十四主星·星曜神学（重构版）

## 紫微：帝曜主贵，性高傲而重格局

### 一、星曜本义
- 紫微为帝星，主尊贵、威权与高格，气质不凡，厌弃低俗凡庸。
- 其成格之要在三方四正是否得六吉星辅弼，尤重左辅、右弼；得辅弼则贵显，无之则仅为紫微独坐，层次大减。
- 紫微坐命，高傲外显，易以己度人、轻视他人；入福德宫，则心高气傲、思想高端，其傲藏于内而不外露。
- 紫微与天府同宫，贵气相叠，亦傲气相叠，常嫌他人想法凡庸、品位低下。
- 紫微在外宫（迁移），行止显贵、气势夺人；逢化权则更增强势、豪气与压迫感。

### 二、逐宫象意
| 宫位 | 象意 | 备注 |
|---|---|---|
| 命宫 | 紫微（尤其紫微天府同宫）高傲外露，气质尊贵，易显傲态、看不起人。 |  |
| 福德宫 | 心思高端，品位不凡，不落低俗；内心高傲，嫌弃庸俗。 | 在福德较命宫为隐。 |
| 夫妻宫 | 破军居夫妻宫者，配偶喜新鲜感、刺激，偏好能带来惊喜、突破自我认知范围之异性。 | 多见于紫微天府坐命之搭配。 |
| 迁移宫 | 紫微（或紫微天府）在外强势、豪气、大气，表现高贵，予人“非常厉害”之感；若加化权，威势尤显。 | 外出易得贵人尊敬，所遇多为富贵有资、从事地产或大企业之人。 |

### 三、组合与判定要点
- 紫微论格，首查三方四正是否会见六吉星，尤以左辅、右弼为最关键；无左辅右弼，只作紫微独坐，格局降等。
- 紫微天府同宫，主老板格、管理格、社会上具地位之人，自带贵气。
- 紫微或天府在迁移宫，外出多得贵人敬重，所交往者多为富贵有资源之人，亦常与房地产、大企业老板往来。
- 紫微天府之贵人，多非直接金钱扶持，而是给予建议、方向点醒；能听取并付诸实行，其人即为其贵人。
- 天府与紫微同属贵曜，天府为南斗主星，性稳、主库藏、擅于统筹庶务、性好积聚，贵气与紫微相通。
- 破军居夫妻宫，主配偶追求新鲜感与刺激，非平淡无奇之选。

## 天机：主聪明机变、善谋好动的辅弼之星

### 一、星曜本义
- 天机主聪明、机敏、点子多，善谋划，性情善良，多居副贰、二把手之位。
- 其性好动不喜静止，喜变动，故主善变。
- 天机化忌则聪明反被聪明误，主钻牛角尖、想不通、思绪纷乱；坐命、坐福德同论。
- 天机与空劫同守命宫，主与武术、宗教、设计等玄异技艺有缘。
- 自化者，本宫宫干之四化飞入本宫、自己化给自己，象征消散、溢出、忌满；自化忌尤凶。

### 二、逐宫象意

| 宫位 | 象意 | 备注 |
|---|---|---|
| 命宫 | 善良聪慧，点子多，善变，宜为辅佐之才；化忌则钻牛角尖、脑子乱。 | 与空劫同宫，主与武术、宗教、设计有缘。 |
| 田宅宫 | 武曲坐守则家庭物质、关爱不缺；太阴、天同、天机守而化禄，主家庭和乐、家境不薄。 | 若逢冲破，则吉性受损。 |
| 福德宫 | 天机擎羊或破军擎羊守之，主想极端、抑郁、情绪激动，甚则自伤；太阴同论。 | 化忌、自化忌并见，尤增纷乱。 |
| 迁移宫 | 与武曲、太阳、贪狼、八座等会照冲命，主外出易有车祸、意外、金属外伤。 | 命迁子田线见擎羊、天机尤验。 |

### 三、组合与判定要点
- 天机坐命，以聪慧机变为体；化忌则主牛角尖、心绪不宁，在命、在福德皆然。
- 廉贞化忌与天机化忌同象，主想不开、想不通、脑子乱，坐命、坐福德同断。
- 天机擎羊或破军擎羊守福德，主内心有刀、偏激抑郁、易有自伤；天机、太阴皆主思虑重，同参。
- 命迁子田线见擎羊、天机，为“车子”星曜；天机化忌冲命，主车祸、外出意外、被砸、金属割伤刮伤等外伤。
- 迁移宫见武曲、太阳、天机、贪狼、八座等冲命，亦主外出有车祸及意外。
- 命宫或田宅宫见武曲，主家庭物质、关爱不缺；见太阴、天同、天机化禄，主家庭和睦、条件优越；受冲破则减吉。
- 天机需天魁、天钺扶助，若无魁钺，如武曲无左辅右弼，主困顿难发。
- 武曲会左辅右弼，主钱财丰厚；武曲无左右，则少心机、易被诓骗。
- 紫微、天府、天梁、太阳之化权欲管束天同、天机所守之宫，基础上未必能制。

## 太阳：东升西落之动星，主光明、无私、清贵，兼刺桃花与是非

### 一、星曜本义
- 太阳东升西落，性属动星；其所入之宫，多主无私奉献、付出与消耗，然此耗为无私之耗，异于破军。
- 太阳兼具刺桃花之性，又与廉贞清白格相关，故其性情复杂。
- 太阳为清贵星曜，与紫微、天府、天梁、天魁、天钺同具重颜面、不屑低端营生之象；然不屑不等于终身不为。
- 太阳化禄，主阳光、高大、开朗、主动、热情之男性；问婚配者，应于太阳化禄之运限。

### 二、逐宫象意
| 宫位 | 象意 | 备注 |
|---|---|---|
| 命宫 | 文昌、文曲、巨门、廉贞、太阳化忌聚此，主合同文书、担保之患，易生烦恼 | 不宜为人作担保 |
| 父母宫 | 同具文昌、文曲、巨门、廉贞、太阳化忌之象，主文书契约、担保是非 | 尤忌替人担保 |
| 财帛宫 | 官司是非之关键宫位；见廉贞、文昌、文曲、太阳、巨门化忌，主财务纠纷 | 与官禄、田宅并参 |
| 官禄宫 | 官司是非之关键宫位；见廉贞、文昌、文曲、太阳、巨门化忌，主事业官非 | 与财帛、田宅并参 |
| 田宅宫 | 官司是非之关键宫位，亦主职业天赋；廉贞化忌居此，官非牢狱之险尤重 | 与财帛、官禄并参 |
| 迁移宫 | 武曲、太阳、天机、贪狼、八座等星冲命，外出易有车祸及意外 | 远行须慎 |
| 光明线（原文音转作“富极县”） | 是非星曜徘徊之处，能加重官非、牢狱、反社会之象 | 原文以此线称“光明线” |

### 三、组合与判定要点
- 太阳化忌会官符，并见巨门、廉贞、文昌、文曲化忌，分布于官禄、田宅、财帛、迁移、光明线，主官非讼狱；其中廉贞化忌为囚。
- 命宫或父母宫见文昌、文曲、巨门、廉贞、太阳化忌者，不宜为人作担保，合同文书易出问题；忌星聚于何宫，何宫之事即成为烦恼之源。
- 财帛、官禄、田宅三宫见廉贞、文昌、文曲、太阳、巨门化忌，并于光明线徘徊，主官司是非。
- 迁移宫见武曲、太阳、天机、贪狼、八座冲命，主外出车祸及意外。
- 运限逢七杀、擎羊，又见廉贞化忌在田宅、官禄，兼巨门、太阳化忌聚于负极官田一线（原文音转，即上文光明线/富极县与官禄、田宅之合称），若命宫同构，主吃官司、反社会、坐牢。
- 田宅宫见太阳（与天同、天梁、天机并论），可参职业天赋。
- 紫微、天府、天梁、太阳为大星；若仅得天同、天机等小星化权来管束，其力不足，未必能制。
- 太阳与紫微、天府、天梁、天魁、天钺等清贵星曜同有气高、要面子、不屑低端营生之性。

## 天同：主福与家庭和睦，体貌丰润亲和，然女命逢之婚姻易居次位

### 一、星曜本义
- 天同乃福星，主家境优越、家庭和睦，能予人良好感受与助力。
- 形貌多肉圆润，性具亲和力，呈人畜无害之质。
- 天同化忌，主自身及家宅承受不悦与困扰；若与巨门同度逢忌，主口舌争吵。
- 星曜（如天同、武曲、巨门、天府等）可脱离宫位独立提取，单论人之言谈特质与财禄状态。

### 二、逐宫象意
| 宫位 | 象意 | 备注 |
|---|---|---|
| 命宫 | 女命坐天同，易居次位（如作妾、二婚），纵为正室亦主夫有新欢、自身遭嫌，婚姻中难握主导权。 | 原文论及 |
| 夫妻宫 | 易处次要地位，或遭配偶嫌弃、伴侣出轨。本命夫妻宫可飞化碰撞大运盘（如化忌入大运福德宫）。 | 原文论及 |
| 田宅宫 | 主家境不差、家庭协和；逢化禄，予家庭极佳感受；逢化忌，主家宅不悦。 | 原文论及 |
| 子女宫 | 须与天同星同参，天同星象不佳则子女亦劣。子息若遇重疾，须看多架构叠加之最终结果，不拘于飞化过程。 | 原文论及 |
| 财帛宫 | 若化忌冲交友，复逢自化权等架构叠加，断为自不量力之局。 | 原文论及 |
| 福德宫 | 承接本命夫妻宫飞忌之冲克与碰撞。 | 原文论及 |

### 三、组合与判定要点
- **机同组合**：天机天同结构，纵三方四正与飞化不佳，凶险亦减，纵失亦平稳；此星系极重地理环境位置。天机化忌未必主分离，惟天同巨门化忌易主争吵。
- **宫星同参**：论子息须兼看太阳与天同，且必须被引动，方合高阶论命之则。
- **多架构叙事**：命盘断验不可仅凭单一架构。如紫微天府与天同星系交涉，若财帛化忌冲交友叠加化权等，须多架构合参。子息重疾亦然，不论飞化历程，唯取多架构最终之果决。
- **运限破军冲克**：大运夫妻宫踩破军，主胆大豁出；若化忌入本命命宫或财帛宫，主钱财遭另一半夺取。

## 天府：库储之星，主稳定掌理与贵气，善后勤而不张扬，重资产之积聚与盘整。

### 一、星曜本义
- 天府为库储之星，性主稳定，不喜激进张扬。
- 天府善后勤管理，能理顺繁杂文件与事务。
- 天府带贵气，若与紫微同宫，其贵更显，然亦易生傲气。
- 单论天府时，可独立观其所主事项之状态，不囿于宫位。

### 二、逐宫象意
| 宫位 | 象意 | 备注 |
|---|---|---|
| 命宫 | 紫微天府同宫，傲气外显，易轻人 | 嫌他人想法低端 |
| 福德宫 | 紫微天府同宫，内心高傲 | 较命宫为隐 |
| 兄弟宫 | 感情稳定，无大波动 | 因谨慎对待 |
| 子女宫 | 易涉资产争议 | 与武曲化禄同宫时亦主置业可能 |
| 田宅宫 | 主资产事项，或置业或争议 | 见三台及多星四化时买房概率大 |
| 父母宫 | 父掌权、文质彬彬 | 不可单断父能干；化科主以科得父/领导之助 |

### 三、组合与判定要点
- 紫微天府同宫，贵气加傲气，命宫则外显，福德宫则内藏。
- 紫微天府如老师傅级别，带贵气；其贵人之力见于给建议，听者能行则成。
- 天府与天同、紫微同会，若命三方四正不佳，财帛化忌冲交友等架构叠加，化权反主自不量力；须多架构合参，不可单架构轻断。
- 天府与禄存同类，皆主储存稳定，不激进。
- 天府在子女宫、田宅宫，遇武曲化禄，主资产事项，或为置业，或为资产争议；若再见私化，买房概率更高。
- 田宅宫、子女宫见天府，配合太阴、天梁、紫微四化及三台，大概率主买房。
- 天府在父母宫，主父亲在家掌权、文质彬彬，须结合天地人综合判断，不可单凭一星断父亲能干。
- 天府化科在父母宫，有天钺同会（底本原作「天月」，实指天钺），主以科之形式得父亲或社会领导之助。
- 单论天府（及武曲、巨门、天同等），可独立观其所主事项之状态，不必占宫而读。

## 太阴：阴主女性、情感、家庭与血分，化禄则情深财助，化忌则女缘破损、婚缘不利

### 一、星曜本义
- 太阴为阴水之星，主女性、母亲、妻子、女儿及家中女性长辈；亦主情感、阴柔、感受、回忆与血分。
- 太阴化禄：主因感情而得财利，与爱侣情深情浓、有情调，缘分深厚，易早恋。
- 太阴化忌：主女性缘薄、助力不足，与母、祖母、婆婆等女性长辈沟通生隙；女命婚姻尤忌。
- 太阴与太阳一正一反，太阴象女、太阳象男；日月反背则阴阳颠倒，相关事象多围绕女性、阴私、情感波动展开。
- 太阴重情怀旧，易感于过往恋情，多愁善感、哭泣追悔，易错过正缘而迟婚。
