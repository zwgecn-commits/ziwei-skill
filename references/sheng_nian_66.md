# 生年四化落十二宫断语（48条·12宫×4化全覆盖）

> 源：公开课程基础断语整理（工程化改写）。
> 每宫四化齐全；禄/忌按"生年禄/忌在宫"，权/科按"权/科在宫"（源为命宫飞化象意，与生年四化落宫通用）。
> 铁律：一切断语均需"引动才发"，是倾向性/态度，非结果；忌坐≠凶（无煞星主在意/收藏/专注）。

## 生年化禄（十二宫）

| 宫 | 断语 |
|:--|:--|
| 命宫 | 生年禄在命宫=人缘好、乐于助人、慷慨、不轻易小气、不记仇、好相处；通情达理、不固执、好沟通、主动打招呼、合群易接纳别人；不主动伤人、容易有福（需大运引动才发；不代表能说会道，也不代表一生福禄亨通）。 |
| 兄弟宫 | 生年禄在兄弟宫=与母亲缘分较好；兄弟宫主母亲、兄弟姐妹与现金流，经济状况较良好、易周转、兄弟姐妹相处不差；兄弟宫是官禄的疾厄（气数位），现金流充裕利于事业做大做强；禄照交友宫则朋友不少、善沟通、跟朋友相处有优势（是优势不代表一定好，需引动才发）。 |
| 夫妻宫 | 生年禄在夫妻宫=异性缘较好、对另一半有期待、重感情、以禄的方式对待另一半；配偶人缘好、善沟通，也容易早恋、较适合创业（禄转忌入田宅则创业基础佳）；但有禄不见得婚姻好（离婚、聚少离多也不少），已婚者易有新感情、易出轨，好坏要看人看环境（需大运引动才发）。 |
| 子女宫 | 生年禄在子女宫=易有桃花、适合合作合伙赚钱、粉丝多（子女宫是粉丝位，看网红缘看大运）；子女、宠物、车子、投资都较好，易得晚辈青睐、对待晚辈好；性生活愉快、态度较开放、易多一个孩子；晚年晚景较好、在外住得舒服；禄转忌入父疾线则孩子将来有出息（需引动才发）。 |
| 财帛宫 | 生年禄在财帛宫=对待钱财较会享受、钱带来的感受好；赚钱较轻松、收入较好、机会多；禄主得、主享受，但禄不特别善于理财、偏享受花钱；不代表发财，能否发财由本命+大运共同决定（忌见禄比双禄更利爆发，需引动才发）。 |
| 疾厄宫 | 生年禄在疾厄宫=乐观开朗、心宽体胖、易发胖、脾气好、好商量；待人处事不错、有真才实学、情商较高；照父母宫则说话不直、易照顾别人脸面、不伤人；办公环境较和谐、办公室较大；但易懒、随遇而安、不特别积极、喜欢享受；不代表不生病（忌坐或忌冲该生病仍生病，需引动）。 |
| 迁移宫 | 生年禄在迁移宫=一生适合外出发展，外面易遇到好的人事物、在外吃得开；善察言观色、机会多、外缘好、适合在外赚钱；迁移主平台，选的平台较好、对外圆融；出差谈项目谈业务办事较顺、情商较高；禄转忌入财帛则在外挣钱较顺利（需引动才发）。 |
| 交友宫 | 生年禄在交友宫=朋友多、人缘好、热情好客、善沟通，与同事朋友相处不错；朋友值得交（禄相处轻松，忌则讲义气沉重）；禄照兄弟宫则现金流不缺、好借钱、找工作容易（人气与希望）；但大运走不好该失去的朋友仍会失去（需引动）。 |
| 官禄宫 | 生年禄在官禄宫=官禄是命宫的气数位（公众行为），得禄则公众行为优秀、运气较好；工作易上手易胜任、做得较开心、职场较顺；禄主掌薪（升职以权为主，官禄最好画权）；照财帛宫收入尚可；大运禄过来需防婚外情（已婚者注意），需引动才发。 |
| 田宅宫 | 生年禄在田宅宫=家缘好、对待家庭和睦共处；房子较大、住房环境/邻里/地段较好、易不动产增值；第一大限田宅叠大运田宅则家经济上升或买房（定盘好用）；适合多置产业，禄转忌入财帛可出租店面/房子、做房地产/土地出租来财；不代表发财（需运引动，财运六宫位综合看）。 |
| 福德宫 | 生年禄在福德宫=喜欢享受、心态好、较开心、会玩、较贪玩、兴趣广、较聪明、想得开；易成为杂家（什么都会什么都不精）；不太记仇、心大（有煞星/铃星会记仇，但最终表达仍大度）；好享受易做事不积极、易满足现状（三方四正低则易胸无大志）；需引动才发。 |
| 父母宫 | 生年禄在父母宫=笑脸迎人、照顾别人脸面、善表达、和颜悦色、脾气好；照疾厄宫则性格好、长辈缘好、孝顺；考运/证书/名声较好（不冲破为佳）；禄转忌入官禄则适合国企/公务员、得长辈领导青睐、利读书考运；父母是夫妻的田宅（另一半家庭不差）、是子女的官禄（子女找工先天优势好）；状态差则防阿谀奉承、虚伪（需引动）。 |

## 生年化权（十二宫）

| 宫 | 断语 |
|:--|:--|
| 命宫 | 权在命宫（自化权）=权主权柄、权力、自信、权威、霸道、专权、不服输；自化权会失去权力（过于霸道专权滥用而失，或权力不够被迫放弃）；权为小忌，比忌还难沟通，会顶人、有刺儿、霸道、有自己的认知并表达出来；过于自信自负滥用权力会失去权力（倾向性/过程，需看生年权在何宫与引动）。 |
| 兄弟宫 | 权在兄弟宫=兄弟宫是官禄的疾厄（希望/远景），权入兄弟对开创事业有主动积极的建议与主见、对未来事业有主观判断，厂房/公司能否做大看兄弟；权照交友，以权的方式谈事业会让人略反感（小忌冲）但不影响交友关系（禄科较舒服）；权主掌控管束，严厉但方向不一定错（倾向性，需引动）。 |
| 夫妻宫 | 权在夫妻宫=自己择偶有主见有标准、不需别人插手，对另一半有控制欲；谈感情较理智、较直男/死板（对比禄入夫妻你侬我侬）；权主掌控、严厉，方向不一定错但表达方式让人不爽（倾向性，需看星曜强弱与大运引动，不代表结果）。 |
| 子女宫 | 权在子女宫=对子女管教严厉、管束严格、方向没错（忌入子女是溺爱、方向错）；桃花方面无太多桃花概念，性方面较生猛、房事过度、掌控强势；合作方面想控制合作人、想占主导权（能否占得到看子女宫飞化、生年权在不在我宫）；权照田宅则在家有权威、能管理家庭（倾向性，需引动）。 |
| 财帛宫 | 权在财帛宫=命宫化权入财帛则喜欢挣大笔的钱、看不上小钱、一笔一笔地挣；权照福德则爱面子、讲排场、敢赚敢花、铺张浪费、钱能壮胆；命宫是财帛的气数位，本人挣钱倾向一笔一笔挣；权主大、主开阔，是过程不是结果（倾向性，需看大运禄忌引动，不代表能挣到）。 |
| 疾厄宫 | 权在疾厄宫=疾厄是官禄的疾厄（身体与办公环境），权入疾厄则管理自己、公司、厂房、商店，象意与权入父母差不多（倾向性，需引动才落实）。 |
| 迁移宫 | 权在迁移宫=整体架构高则外出有牌面、掌权出去坐上客、事业有成、大家恭维；成就不高/三方差则在外易自负、易与人争执不欢而散；权在迁移走出去自信、干练、处事应变能力强，想掌控外面的舞台局面（能力强则掌控得了，能力弱则易争执）；倾向性，需看三方四正/命格与大运引动，不代表结果。 |
| 交友宫 | 权在交友宫=人缘还不错（虽是小忌），想在朋友圈中当老大、想掌控朋友圈；好的一面是想当大哥照顾兄弟、有面子、仗义；三方差则想显摆、没人搭理、死要面子活受罪；交朋友有自己的主见（心里有杆秤）；有能力易替别人出头、热心仗义管朋友（倾向性，需引动）。 |
| 官禄宫 | 权在官禄宫=权落官禄最好，掌控自己的事业、对事业有认知有自信有抱负；工作能力强、善管理、事业易成功；官禄喜作权，工作上进取、有开创力、利于升迁、适合开发性项目（权胆子大、开拓）；格调不高则成技术权威、老师傅、靠技术吃饭（权也代表技术）；权照夫妻配偶较强势；是过程不是结果，需看大运禄忌引动（不代表一定升职）。 |
| 田宅宫 | 权在田宅宫=在家掌权、掌控自己的财库，权能解忌（忌冲田宅破财库时权能控制留一部分）；对子女管教较严厉、家里说话有地位、通常是一家之主；选房子有主见、喜欢住大房子、气派高大的房子（倾向，不代表能住）；家里可能开超市/商店/房屋出租，需管理田宅财库（倾向性，需看大运与三方四正引动）。 |
| 福德宫 | 权在福德宫=福德有权的人太自信太有主见、不太好沟通（权为小忌）；权在福德不表现出来，内心有一套恒定标准、心里有杆秤、不好相处；权为小忌，重视享受、摆阔、用钱无节制（权冲财帛给财富线胆子大）；胆子大、大开大合、敢赚敢花、好大喜功、内心不服（嘴答应心不服）；倾向性，需看生年权在何宫与引动。 |
| 父母宫 | 权在父母宫=父母是人的脸面（长相看父疾线），权入父母则表情易横冲直撞、大嗓门、霸气、得理不饶人，防傲慢失礼偏见、易惹是非；父母主学业学历考运，善于读书、利学业利证书；父母是子女的事业（可能成就孩子的事业）、是交友的财帛（控制对方钱财、可能做生意）；与长辈易争执、得理不饶人、不礼貌易得罪人（对待长辈宜禄科不宜太有主见）；倾向性，需引动。 |

## 生年化科（十二宫）

| 宫 | 断语 |
|:--|:--|
| 命宫 | 科在命宫（生年科）=科主平顺、贵人、名气、功名、源源不断、风度、博学；科在命有风度、文质彬彬、有气质、斯斯文文、博学；命宫做科最好（度把握得好，不像禄热情、不像权屌、不像忌固执），易吸引贵人、命中自带贵人；命格走好运才有名气（需走好运/引动；科主虚、倾向性）。 |
| 兄弟宫 | 科在兄弟宫=对兄弟关心一般、随和，不主动联系、不热情不主张，但有事会帮；君子之交淡如水，不热情但长久、绵绵不断、藕断丝连、时间线长；有计划有商量、相处和谐、做事有目标分层次；兄弟宫是现金流，理财量入为出、经济平顺平稳、现金流波动不大；兄弟是官禄的疾厄，对事业无太大企图心、从长计议、一步一步走不求大突破；科主虚/倾向性，需引动。 |
| 夫妻宫 | 科在夫妻宫=对另一半随和、易相处，倾向于找有气质、漂亮、有文艺气息、对才艺感兴趣的异性；对待方式柔、相敬如宾、客客气气、度拿捏得好（比禄还好）；科主长情、藕断丝连，离婚拖拉、离完仍藕断丝连；科解忌=拉长+保守治疗；遇桃花心防第三者介入；科不太会明确拒绝（让人等通知）；科见忌较折磨人；科主虚/倾向性，需引动。 |
| 子女宫 | 科在子女宫=对待孩子晚辈和气、讲道理、民主、和蔼可亲、没架子；与合作人有商有量、和和气气、有一说一、有条理；教育子女方法恰当、利于孩子学习；科入任何宫都层层递进、恰到好处、合适到位；桃花方面保持联系绵绵不绝、桃花不断但不太强烈；科主虚/倾向性，需引动。 |
| 财帛宫 | 科在财帛宫=花钱量入为出、钱财欲望不强、过得去就好、不铺张浪费（可能爱点面子）；对钱财态度合适（中庸）、量入为出；科主贵人才，需要花钱时总有人帮；科主名气，赚钱源源不断、适合上班领薪水、平顺、心态好、温饱、方便小周转；适合小生意小投资、细水长流之财；科主虚/倾向性，需引动。 |
| 疾厄宫 | 科在疾厄宫=身体有气质、体型恰到好处、不胖不瘦、举止文雅、身形好；健康良好平顺、不太容易生病，即便生病治疗也平顺渡过、不严重；性格和气、少戾气、温文尔雅、不急不躁；科在我宫代表有气质（在他宫不能断有名气）；科主虚/倾向性，需引动。 |
| 迁移宫 | 科在迁移宫=在外文质彬彬、儒雅斯文、随和自在、人缘好，既不热烈也不冷淡；在外易获好名声（别人念叨你这个人好相处）；在外易吸引贵人、得别人帮助；易从事文化教育、艺术类（科主文艺艺术、文职文科文教）；科主虚（虚假机会）、倾向性，需看三方四正与大运引动（不代表一定成名）。 |
| 交友宫 | 科在交友宫=君子之交淡如水，友情绵绵不绝、不热烈但长久；朋友圈口碑好；科在哪里哪里就平顺（交友失去联系再联系时情谊仍在）；喜欢交温文尔雅、爱读书、气质温和的朋友；科主虚/倾向性，需引动。 |
| 官禄宫 | 科在官禄宫=对待工作防魄力不足、得过且过、不太上心、平稳、觉得安稳就好；易从事文职策划类、偏艺术一方面；喜欢安稳平稳上班、不争不抢、平稳有余；处理工作恰到好处（从人的角度）；不太利于晋升（科来官禄不太合适，做艺术方面更合适）；科主虚/倾向性，需引动。 |
| 田宅宫 | 科在田宅宫=喜欢朴实、幽静、书香环境（竹林、木质、优雅房子）；对家庭沟通、关系处理合适到位，不热情不冲动不激进，家里面平顺；财库平稳稳定、无大爆发也无大下降；科在哪里哪里就平顺稳定；科主虚/倾向性，需引动。 |
| 福德宫 | 科在福德宫=把平顺带到福德，心安、心情平和、心静心定、内心波动不大；接近开悟、心平定，不虚荣、不激动冲动；福德是财路财缘，财源稳定、不是很多也不是特别少；心态好；科主虚，实际得失看生年禄/大运禄/流年禄引动（倾向性）。 |
| 父母宫 | 科在父母宫=父母是名声位，爱惜自己名誉（不是要面子）；对父母孝顺和睦、有情，可能不常联系不说话但情谊一直在、处理合适；父母是脸面，表达方式斯文平和、文字秀气；矛盾架构：命宫化忌入疾厄冲父母会打破曾爱惜的名誉（先破后立或先立后破）；科主虚/倾向性，需引动。 |

## 生年化忌（十二宫）

| 宫 | 断语 |
|:--|:--|
| 命宫 | 生年忌在命宫=自尊心强、在意自己的想法、较固执己见、专注自己；忌主专注/在意/收藏/管束，忌坐冲迁移宫则较内向、木讷、不擅沟通，适合钻研做专家、不适合交际类工作；无煞星不凶，配擎羊则难沟通、防备心强、缘薄；忌坐主烦恼，需大运禄/科引动才转变（不代表一生如此）。 |
