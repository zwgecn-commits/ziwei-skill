## 一、阴阳两仪法全解
来源: 高阶课第三讲"四化进阶独门技法：阴阳两仪法"

### 核心原理
生年四化分两组阴阳对立：
- 禄 + 忌 = 阴阳对立组（得与失）
- 权 + 科 = 阴阳互补组（主动与被动）

### 断命公式
1. 先定禄忌在哪两个宫位组 → 确定得失的主战场
2. 再看权科在哪两个宫位组 → 确定能力的施展方向
3. 最后看自化 → 确定能量的流向和转化

### 实战口诀
- "禄在何方得在何方，忌在何处失在何处"
- "权科并见论成败，禄忌同参断得失"
- "向心自化来是得，离心自化去是失"

## 二、有效飞宫判断法
来源: 高阶课第六讲"有效飞宫的判断技巧"

### 判定
- 阴阳方向 → 禄=正向 / 忌=逆向

### 有效性铁律
- 飞入六内(命财疾官田福) = 有效飞宫
- 飞入六外(兄夫子交友父迁) = 虚象
- 飞宫遇自化 = 抵消

## 三、自化能量体系
来源: 高阶课第七-八讲

### 两种自化
- 向心自化 = 能量回收（得）
- 离心自化 = 能量发散（失）

### 自化与生年四化互动
- 生年禄+向心自化禄 → 双禄
- 生年忌+离心自化忌 → 双忌
- 生年禄+离心自化禄 → 禄被化掉
