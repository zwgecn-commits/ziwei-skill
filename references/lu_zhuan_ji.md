## 〇、忌之本性与解忌总纲（先读）

1. **忌的本意只有一个：在意**。书上所列遗憾/不圆满/堵塞/执着/压迫全由「在意」衍生。断忌先不读凶，只读「我在意某宫的人事物」；配上星曜后才由星曜性质定事件方向。口诀：**忌是在意非纯凶，因意生执方有厄**。
2. **忌是自私的**：在意的事情要求回报（吸纳功能）。禄=开开心心给出去不求归还；忌=抠抠搜搜给出心里等回馈。命宫化忌入交友=你在意朋友同时也希望朋友对你好。
3. **「你在意的地方往往有问题」**：没有问题你不会去在意，在意本身就是问题的投射（命忌入财帛=觉得钱不够；入夫妻=担心对方；入官禄=事业有缺陷压力）。学着把视线移开，伤害也减轻。
4. **生年忌坐宫总则**：我宫(命财官田)忌坐=藏/在意/收藏，可做（不可冲一六九）；他宫忌入冲我宫=主损。无煞不凶，有煞(羊陀火铃)才显凶——忌加煞星对宫冲射力强。
5. **忌坐≠离婚格/破财格**：忌在夫妻宫不是离婚格（忌入子女冲田宅或再转忌冲命才是离婚结构）；忌坐财帛不代表没钱——看飞化引动与解法。

## 一、禄转忌 vs 忌转忌（钦天核心技法）

| | 禄转忌 | 忌转忌 |
|:--|:--|:--|
| 定义 | 本宫有生年禄/化禄 → 以该宫宫干化忌入他宫 | 本宫有生年忌/化忌 → 再以宫干化忌入他宫 |
| 性质 | 吉象延伸：等同目标宫有生年禄效果，把好处带去 | 凶象连锁：把执着压力算入另一宫，苦上加苦 |
| 能量 | 比单纯化禄能量更大（来自人生最在意的点，星曜+四化能量最大化传递；带禄权科付出既好且重） | 执念加深、事态沉重、旧结翻搅 |
| 断法 | 先辨源头是禄是忌，再定性质是助力还是业力 | 借权科煞星位置断方法或延宕 |

- 例：命宫有禄转忌入财帛=靠自身优势能力人格魅力挣钱，自食其力；因转忌冲福德主为求财少享乐，但源为禄属「禄照」非「忌冲」，伤害不大（带三成冲伤可忽略；若财帛本宫无禄纯忌转，冲福德之伤百分百成立）。
- 例：财帛宫化忌入交友冲父母≠没救——大运交友化禄则成「禄转忌入交友照父母」，此运反主有钱可炫耀能利益父母。**切莫执原局一冲定终身**。

## 二、禄逢冲破

1. 定义：一线上一禄一忌相对（禄入某宫后被相邻宫位之忌冲克或自化忌引动），吉象受损——**先得后失、福中带祸**：先有一段好感情/好机会，最终被冲散，比无禄纯忌冲更痛苦（无禄纯忌冲多主空虚难有良缘，未必很凶）。
2. 解盘三步：① 被冲之禄原在何宫（我宫被冲=得中有失聚散无常；他宫被冲=吉象外流终属虚花）② 忌由何宫而来（他宫直冲=防对宫之恶；本宫自化忌=祸由自身疏忽决策）③ 何时应数（大运流年引动才显）。
3. 论法要义：**用不能冲体**（体=先天命局生年四化与三方结构；用=后天飞化自化）。用去冲体则体破，得财亦终空；禄忌同源或忌能转禄则未必全破。勿见禄喜，须观后化。

## 三、忌出

- 忌出=生年忌或命忌化出后迁出他宫、未停本宫：烦恼宣泄于外，多应迁移/人际/外出事务；忌入他宫未出=该宫事务纠缠心中难解。
- **忌出四来源枚举**：①本宫自化忌出 ②忌入对宫 ③忌入迁移 ④忌入父母——四者皆属忌出之列，以①本宫自化忌出之害最重；忌出宫位之人事物主消失离散（如交友宫自化忌=被朋友设计骗财）。忌出与忌入相对：忌入主藏敛付出，两者本质相反，勿混。
- 例：福德宫有禄转忌入财帛=将爱好商业化赚钱（摄影改拍商业题材），过程中快乐减少；禄转忌与自化忌不同——**禄转忌禄不消散，为先得后转**，此象为吉，靠兴趣获利只是需调整模式。

## 四、禄权科解忌（解忌的三种方式）

| 解法 | 方式 | 副作用 |
|:--|:--|:--|
| **忌见禄=大好** | 一直担心的事变好：忌宫见禄（大运化禄入），获得经验与修复机会 | 并非把忌从根拔除，而是改变忌的行为方式，凶性大减；经验烙在阅历上提升认知 |
| **权解忌** | 快刀斩乱麻一次解决（肿瘤切除/一句话离婚/控制不花） | 权为小忌态度强硬，易生争执冲突肢体摩擦；叠煞更显——痛但有效 |
| **科解忌** | 保守治疗延长过程（喊着离却拖数年） | 不除根只缓痛；看似解忌实为转念 |
| 禄能解忌吗 | 严格论不能根除；以正面资源经验填补忌之缺陷，影响降低不因遗憾而苦 | 统一理解：禄权科皆「改变忌的行为方式」，结果面看似解忌 |

## 五、生年忌十二宫解忌引导（逐宫解法要点）

> 生年忌逐宫象意查 `sheng_nian_66.md`；此处只列「解忌引导」——《如何解忌》专题核心：**不用画符买东西玄学配件，靠改变自身解忌**；此法能解大部分忌，个别因人而异。

- **命宫**：忌坐命=心性专注研究型，不善沟通较木讷——解：做研究工作/专业深耕，忌见禄（大运禄来）口才反超常人；无煞自处勿强求社交。
- **兄弟宫**（现金流）：忌入=现金流有问题，公司不宜做大、招人宜少（冲交友）——解：做小公司大收益。
- **夫妻宫**：忌坐夫妻≠离婚格——解：①不适合固定打卡工作，宜经常出差/走动/自由职业（被逼换工作=被动应象）②感情上保持聚少离多（煞多时最佳解法）③运走得好也可创业（夫妻忌在命/财帛宫皆还行，看大运）。忌冲官禄=对配偶/事业的牵挂；夫妻忌主"该结婚了/不得不"，权=该结婚，科=物色寻找。
- **子女宫**：忌入冲田宅——谨慎投资合伙（桃花/投资/子女三职）；大运吉可解。
- **财帛宫**：忌坐=在意钱想挣钱，可专精一门技术得财（体力/手艺型），不体面也挣钱——忌见禄该运多发大财（先难后得，仅限该大运）。
- **疾厄宫**：忌入=身体劳碌操心（体力活挣钱辛苦）——忌冲父母上不了台面，宜正途避免借贷担保。
- **迁移宫**：忌冲命=宜外出发展，不出去才华难伸（本地憋屈，出去破局）；说话太直无心机要学委婉；无煞直接出国远行不凶，有擎羊防车祸外伤。
- **交友宫**：忌入=重情义的朋友/亏欠式在意；比化禄更讲义气（打架时禄的朋友散打高手替你挡拳，忌的朋友身体单薄照样真上）。
- **官禄宫**：忌入=事业责任感应强，适合上班/专业匠人，不宜做大老板（事必躬亲）；遇科名望彰显、遇权掌实权。
- **田宅宫**：忌入=在意家庭财库；忌坐田宅可论有房产（在意则置得）——须防为房耗财；大运禄来解。
- **福德宫**：忌入=精神内耗思虑多（福分靠自我修持）——解：借宗教艺术寄情、知识体验化解，大运禄入福德建立精神寄托越活越清明。
- **父母宫**：忌入=与长辈/文书缘淡（考运证书防文书疏失）；解忌看父母宫无煞有煞之分，无煞主在意孝顺。
- **通用**：忌坐之宫若有煞（擎羊陀罗火铃）凶性加强，无煞只是在意/收藏/专注；忌冲之宫损失更多——**解忌先解忌冲之宫**。

## 六、断财补充（禄转忌要点）

- 财帛宫化禄只是「现金流增加」：不配合事业格局与态度转变，打卡上班者只应加薪几百——勿轻言暴发。
- 看财运三宫：命宫化禄=现金流充裕；官禄化禄=此大运收入提高；财帛化禄最弱（仅主有钱挣）；量级看星曜（贪狼化禄=大财）。
- 火贪格 vs 贪狼化禄：格局不重要，飞化架构才是核心——贪狼化禄不管有无火铃都是大财，火铃只是爆发感更强更快；不可只记格局断吉凶。
- 田宅宫有生年禄≠一出生家境好：须看是否武曲化禄及大运引动；**大运田宅化禄=主得房产**（可自行验证）。
