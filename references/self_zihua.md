## 〇、自化总纲（先读）

1. **自化=宫干四化飞不出去、自冲本宫**：主消散、溢出；忌满则倾（自化忌能量最强）。
2. **四曜自化本性**：自化禄=付出给予，用得好人缘佳、能洒脱放下、自我疗愈；自化权=掌控主导、事必躬亲（放权仍监督），霸气强硬有人缘起伏；自化科=名顺才华粉饰（贵人/面子），防虚浮拖沓；自化忌=在意执着痛苦无奈、无缘、先得后失。
3. **向心/离心**：箭头往内=向心（有目标之消散，如财帛自化忌入福德=钱花自己享受）；箭头往外=离心（无方向之消散，需借生年忌找线索）。皆主消散，向心多一层指向性。
4. **自化入本宫=回冲**：力量向内冲射，非向外发射——该宫「自己变化自己受」。

## 一、自化两两组合断法

| 组合 | 断法 |
|:--|:--|
| 自化禄权同宫 | 该宫所主之事自有活力生机，又自我主导、起伏较大；禄权俱为无耗损本性组合，只要不逢自化忌，吉多凶少 |
| 自化禄+自化忌同宫 | 表面蓬勃给力、内里不断流失：虚花不实、反复难持久；人际热络藏疏离、金钱赚得到留不住 |
| 生年禄逢自化忌（同宫） | 先得后失：禄入该宫亦有财来财去；若转忌入田宅/福德等库位反主置业置产、藏忌于库非全凶（用冲体则败局明显） |
| 权忌交战 + 自化禄 | 禄能调和权忌：矛盾辛苦得以化解，花钱洒脱，不致大败局 |
| 权忌同宫 + 自化权 | 个性刚硬不愿退让，一念执着致交战激烈；忌冲一六特定宫位则成斗局败象；尚可由己力争取 |
| 权忌同宫 + 自化忌 | 权力运用不当而真失：官禄者降职去职、常远调；近无奈失去，最需防 |
| 科 + 自化禄 | 思想有条理、能自我化解烦忧（福德宫=心灵自愈力强）；才学能发挥被认同，不太在意虚名 |
| 科 + 自化权 | 以强硬/权威方式表现才学，锋芒毕露易得罪人失支持；局势需威严时反能以权得名 |
| 官禄自化权 vs 自化忌 | 自化权=掌握实权适合管理/技术话语权，失小；自化忌=权忌交战真失权位，降职去职远调，失大 |

**禄权科忌同宫量级**：官禄得禄+自化忌=「以忌换禄」——频繁换工作但每次薪资反增；不宜久居其职，应转忌他宫方论吉。

## 二、自化忌分宫要旨（自化忌落何宫=与何宫缘分薄）

- **命宫自化忌**：自我设限、固执；箭头向外，大运行限一转即冲迁移——固执不善言辞在外不易受欢迎。
- **夫妻宫自化忌**：感情有始无终/主动退却自我了断；大运再逢忌冲父母或迁移命宫，易应离婚或聚少离多；事业型搭配好仍可事业有成各忙各的（非纯凶）。若子女宫忌入夫妻宫加重，应期倾向**晚婚**（30 岁后成婚居多，非 30 岁必婚）。
- **财帛宫自化忌**：钱存不住留不住；向心忌看忌入何宫定花费去向，离心忌借生年忌找线索（生年忌在田宅=钱投房产）。
- **官禄宫自化忌**：事业不稳定易变动；对工作执着多劳，三方有禄或大运助仍可发达。
- **田宅宫自化忌**：财库破损家宅不安、不动产缘薄；生年忌同宫=先有后失财难聚。
- **福德宫自化忌**：想得多内心纠结、精神自扰、福分淡薄；只论思绪不论实质破败。
- **疾厄宫忌+自化忌**：先有疾厄之体后有自化之失：先天隐患逢大运流年引动爆发、反复难愈；三方有禄可救，星恶则凶性不减。
- **交友宫自化忌**：朋友结交不深、阶段性往来；煞忌加临亦可断受朋友设计、被坑骗破财（倾向断语，须结合星曜成句；子女宫自化忌=与子女缘浅费心难亲近）。
- **自化忌+生年忌同宫**：力量加倍、忌满则损；生年忌在我宫(命财官田)=藏、主我执我存格局可高；生年忌落他宫则难自主、易为外缘所耗。
- **对宫双自化互抵**（判例·倾向性）：相对两宫各有自化时不可论禄忌交战/双忌——如夫妻宫自化忌而对宫官禄宫自化禄，则夫妻相安无事（互抵消解）；若两宫自化同曜（双禄/双忌）则同向叠加，属另一断法。
- **断法口诀**：先看生年忌定凶吉（我宫曰藏可为助力；他宫缘薄难守）→ 再看自化忌落宫（与何宫缘薄必有损耗）→ 三看转忌去向（转库位反主置业）。

## 三、抓忌（忌的实质后果判定）

1. 抓忌=从命宫干或相关宫干飞化，层层追踪忌落点定吉凶枢纽；忌所入处=此事最需防范与解决的关隘。
2. **忌落宫有无禄是分水岭**：他宫飞忌入A宫，A宫有禄→能抓到禄（如交友有禄而飞忌入，可因朋友得财）；A宫有忌→不但得不到反损自己。
3. 判忌之性质须看星曜与该宫内涵：是关心、吸纳、伤害还是夺取（例：命宫化忌入官禄，辨是关心工作还是工作出问题，还是官禄有禄可拿）。
4. 分层看：生年忌/命忌/大限流年忌力道与影响范围不同；飞出之忌同理（忌出=主动奉献出去，如投资送礼；忌冲=被迫不得不花钱，凶性较强）。

## 四、禄因忌果（飞星线索技法·非定论）

1. 定义：禄与忌至少在一条线上构成闭环因果——先看化忌之宫所主之事，再寻化禄之宫，由禄宫解释忌的缘由。
2. 例：命宫化忌入田宅冲子女、禄在财帛=因求财而与子女缘薄；命宫化禄入夫妻再化忌入田宅=因心系婚姻家庭故不需要外面桃花（桃花层有效闭环）。
3. **边界（重要）**：不可在所有宫位套用——若禄宫解释牵强（如命忌入田宅冲子女、禄在夫妻，读"为夫妻与子女无缘"即谬），须回归宫位本能关联（如先查疾厄宫有无生育象意）。提供思路而非标准答案。

## 五、断例参考（多项定一象示范）

- 财帛宫忌出（主动奉献）vs 忌冲（被迫破耗）：心态与主动性不同，断法随宫位星曜调整。
- 命宫化忌入官禄冲夫妻=因事业忽视配偶/工作压力致失和；官禄有禄则事业有成婚缘薄。
- 夫妻宫化忌入子女冲田宅=配偶外桃花破家或子女问题影响家庭（禄在子女/疾厄则外遇之象更明，非定数）。
- 大运夫妻宫化忌冲本命=此大运婚缘不吉，但非必离婚——应期看流年引动，同年同月同日生者表现各异（规律非定数）。

> 总纲：自化/飞化各技法皆为**单一线索**，须多项对应象+大运流转+命主反馈综合成句，单一凶格不铁断终身。
